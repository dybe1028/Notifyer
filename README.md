# Notifyer

Notifyer is a customizable Android reminder app built with Kotlin.

Originally started as a simple countdown reminder project, Notifyer is gradually evolving into a smart reminder system with support for multiple reminder types and user customization.

## Current Features

### Countdown Timers

* Create countdown reminders
* Real-time countdown display
* Run timers manually
* Edit existing timers
* Delete timers

### Reminder Management

* RecyclerView-based reminder list
* Floating Action Button (FAB) for creating reminders
* Automatic refresh when returning to Home
* Empty state support
* Persistent storage using SharedPreferences

### UI Features

* Two-screen workflow
* Clean minimal interface
* Popup actions
* Toast feedback

### Easter Eggs

* Some hidden surprises may exist.
* Spam clicking random things is encouraged at your own risk.
